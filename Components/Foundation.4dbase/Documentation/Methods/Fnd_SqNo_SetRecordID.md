Assumes the number will not be seen by the end user, so the number can't be returned for reuse.If no table is specified, either the current form table or the trigger table will be used.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inTable|Pointer|➡️|A pointer to the table for which to return a number (optional)|
