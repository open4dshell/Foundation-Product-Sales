It steps through each form method, object method and project method that handles On Validate without calling the hook, one at a time, showing the method as it is and, ready to edit, the hook and the method as they would be afterwards. Nothing is written until you click Apply; the first Apply asks whether Foundation may change your database. Originals are saved in Resources/Foundation/OnValidate-Backups when that folder's parent exists.Run it from the Execute Method dialog. Interpreted mode only, with the sources on disk.Attributes: Shared, Preemptive indifferent| Parameters || --- || Does not require any parameters |
