Returns the current value of the Minimum password length.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inMinChars|Longint|➡️|The Minimum password length setting (optional)||inMinLimitation|Longint|➡️|The Minimum value displayed in the pop-up menu (optional)||Result|Longint|⬅️|The currently set Minimum length|
