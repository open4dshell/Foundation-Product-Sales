"Sales.log" will become "Sales (2021-08-11T103809).log.zip"Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inMaximumSize|Longint|➡️|Maximum size in bytes (optional)||Result|Longint|⬅️|Maximum size|
