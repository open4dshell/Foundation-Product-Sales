The same is true when the stored type is object but the stored text isn't valid JSON - the row is treated as not-found rather than raising out of this method.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||itemName|Text|➡️|The preference name||itemValue|Pointer|➡️|Where to put the value if found||inItemOwner|Text|➡️|The owner to read, defaulting to Fnd_Pref_SharedName (optional)||Result|Boolean|⬅️|True if found|
