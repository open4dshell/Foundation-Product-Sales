The setting lives on Fnd.List, so it persists for the session rather than the call.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inBoolean|Boolean|➡️|Turns type-ahead on or off (optional)||Result|Boolean|⬅️|The setting after any change|
