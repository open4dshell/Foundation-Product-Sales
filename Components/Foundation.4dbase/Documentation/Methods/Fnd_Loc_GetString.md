Also replaces any parameters.  For  example, "<<1>>" gets replaced with the first optional parameter, "<<2>>" with the second optional parameter, etc.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||$1|Text|➡️|The Foundation module name||$2|Text|➡️|The internal string label||$3..$n|Text|➡️|Replacement strings (optional)||$0|Text|⬅️|The localized string|
