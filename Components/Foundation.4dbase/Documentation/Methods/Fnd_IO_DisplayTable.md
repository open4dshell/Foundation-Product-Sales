Otherwise a new process is created to display the table.If the optional parameter is passed and is True, a new table is created even if one already exists.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||table|Pointer|➡️|A pointer to the table to display||inForceNew|Boolean|➡️|Open a new window, even if one is already open? (optional)|
