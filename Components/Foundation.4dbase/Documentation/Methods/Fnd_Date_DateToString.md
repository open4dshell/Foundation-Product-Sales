Returns "Today", "Tomorrow", or "Yesterday" if appropriate. This is localized if the Localization component is available.Otherwise returns a short date string.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||input|Date|➡️|The date to convert to a string||inRelativeTo|Date|➡️|The relative date (optional)||inDateFormat|Text|➡️|The date format (eg. "M/D/Y") (optional)||Result|Text|⬅️|The date as a string|
