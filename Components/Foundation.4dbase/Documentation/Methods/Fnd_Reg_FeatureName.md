If you want to use something other than the default values, you'll need to call this method to set up the names before trying to retrieve them or before displaying the registration dialogs.The Application code returns the database name.Other feature codes return "Feature: codename"Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inFeatureCode|Text|➡️|The feature code (optional)||inFeatureName|Text|➡️|The new feature name (optional)||Result|Text|⬅️|The current feature name|
