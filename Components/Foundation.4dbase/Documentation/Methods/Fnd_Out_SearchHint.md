Call it from Fnd\_Hook\_Out\_SearchFields, for the table being opened.The hint is the grey text in the empty box. It is shown as written, never shortened. The tooltip is the help tip on the box and its icon; it may be long and may contain carriage returns. An empty hint or tooltip keeps Foundation's own text: for the hint, the field names that fit; for the tooltip, every field name.Fnd\_Out\_SearchHelp returns that list of field names, so a tooltip can include it, provided it is called after the Fnd\_Out\_AddSearchField lines.```Fnd_Out_SearchHint("Invoice no. or customer"; "Invoice numbers match from the start."+Char(Carriage return)+"Searches: "+Fnd_Out_SearchHelp)```Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||hint|Text|➡️|The grey text in the empty search box||tooltip|Text|➡️|The help tip (optional; default every searched field's name)|
