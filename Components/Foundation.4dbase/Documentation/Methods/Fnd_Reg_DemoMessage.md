If you want to use something other than the default values, you'll need to call this method to set up the names before trying to retrieve them or before displaying the registration dialogs.Pass an empty string to revert to the default message (from the localization strings).Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inFeatureCode|Text|➡️|The feature code (optional)||inMessage|Text|➡️|The new demo message (optional)||Result|Text|⬅️|The current demo message|
