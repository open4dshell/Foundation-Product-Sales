If an item with the specified name isn't found, the default value is returned (if specified). Otherwise, 0 is returned.The scope is a constant - Fnd\_Pref\_Local, Fnd\_Pref\_Server, Fnd\_Pref\_Shared - or a label: any text, naming a namespace of the caller's own in [Fnd\_Pref]. A label is read from that namespace alone, so nothing local shadows it; a constant only says where to store a default that has to be created, and does not filter the read.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||itemName|Text|➡️|The name of the preference item||inItemValue|Real|➡️|The default value (optional)||inItemScope|Variant|➡️|The scope or label if the default is used (optional)||Result|Longint|⬅️|The saved value|
