If the time passed in is up to ten minutes after the quarter hour, the time is rounded down. Otherwise it's rounded up.  Won't round up past 23:59.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inTime|Time|➡️|The time to round||Result|Time|⬅️|The rounded time|
