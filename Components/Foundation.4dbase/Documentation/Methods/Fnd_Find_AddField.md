If a position isn't specified, the field is added to the end of the list.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||field|Pointer|➡️|A pointer to the field to add||inPosition|Longint|➡️|The position in which to add the item (optional)|
