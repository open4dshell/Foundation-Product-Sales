Usually this will be because the user is holding down the bypass key, but there may be other reasons.Sets Fnd.Data.formatError to -1 if True is returned.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||Result|Boolean|⬅️|True if the routine should be bypassed|
