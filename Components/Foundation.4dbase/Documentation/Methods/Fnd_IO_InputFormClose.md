Basically we need to ask the user if the record should be saved if it has been modified.Returns True if the window gets closed.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||Result|Boolean|⬅️|True if the window will be closed.|
