Use in test methods, Foundation's or a host's, in place of ASSERT. A failure is counted, not raised.Nothing interactive happens, so a test behaves the same run from the IDE or headlessly under Fnd\_FCS\_TestRunner. Results are read from the log, or from testResults.json when the runner wrote them.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||ok|Boolean|➡️|The condition being asserted||message|Text|➡️|What was expected, and what was found|
