If the picture already exists in the Cache, it is retreived from there instead of being generated again.Supports these variations: "current" : The currently selected button (Mac OS X Prefs style)Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inIconName|Text|➡️|The name of the icon to use from the 4D picture library||buttonLabel|Text|➡️|The label for the button||inVariation|Text|➡️|The variaton name (optional)||Result|Picture|⬅️|A picture to use for a 4D picture rollover button|
