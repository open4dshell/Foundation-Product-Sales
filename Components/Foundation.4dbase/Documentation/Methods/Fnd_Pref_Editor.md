<!--Fnd_Pref_Editor Does not require any parameters -->## Fnd\_Pref\_EditorFnd\_Pref\_EditorOpens the preferences editor: a list of the stored preferences, with their types and values, editable in place and deletable.Local preferences are listed. Server scoped ones share the same store and are shown when the checkbox asks for them, since a preference that plainly exists should not look missing.```Fnd_Pref_Editor```Attributes: Shared, Invisible, Preemptive indifferent| Parameters || --- || Does not require any parameters |
