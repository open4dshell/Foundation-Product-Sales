It is empty when the address is valid.```$error_i:=Fnd_Data_EmailAddressError("john smith@here.com"; ->$why_t)1, and $why_t is "There is a space in the address."```Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inEmailAddress|Text|➡️|The email address to check||inDescription|Pointer|➡️|Gets a description of the problem (optional)||Result|Longint|⬅️|Error number (0=valid format, 1=invalid format) Based on code posted to the 4D NUG by Owen Watson<owen.watson@paradise.net.nz>.|
