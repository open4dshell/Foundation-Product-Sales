An empty result is the test for "has it gone".Process info would answer this in one line but only from 20 R10, so the answer comes from Process activity, which every supported version has.Process number 0 is not addressable: 4D gives it to its own preemptive processes, several at once. Asking for it returns an empty string.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||processNumber|Integer|➡️|The process number to look up||Result|Text|⬅️|The process name, or "" if it is not running|
