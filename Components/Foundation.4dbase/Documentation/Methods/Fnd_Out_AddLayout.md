Calling this again with the same name replaces the earlier declaration rather than adding a second one.This only declares the layout in memory (Fnd.out.devConfig) - it is not written to Resources/Foundation/Fnd\_Out/<Table>.json. A developer running interpreted can also capture the palette's current widths/order into a built-in layout with Fnd\_Out\_LayoutSaveBuiltIn, which does write the file.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inName|Text|➡️|The layout's name||inVisible|Collection|➡️|fo_field values that should be visible||inTextSize|Integer|➡️|Text size the layout sets (optional)||inRowHeight|Integer|➡️|Row height (in lines) the layout sets (optional)|
