A mismatch is recorded for Fnd\_Gen\_GeneratedReport. A hook holds the host developer's own code, so it is never rewritten. A hook that declares nothing cannot be compared, as its parameters may be typed in a Compiler\_ method; where Foundation passes it parameters or expects a result, it is recorded as left unchanged for the developer to check.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||methodName|Text|➡️|The name of the method to create|
