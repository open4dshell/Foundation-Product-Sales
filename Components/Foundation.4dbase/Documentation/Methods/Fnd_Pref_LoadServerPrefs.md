<!--Fnd_Pref_LoadServerPrefs Does not require any parameters -->## Fnd\_Pref\_LoadServerPrefsFnd\_Pref\_LoadServerPrefsLoads the user's preferences from the database.Does not load the shared preferences, since we need to get those when they're needed, since they may get changed by other users.Called from Fnd\_Pref\_LoadPrefs, which handles the semaphore.Attributes: Shared, Invisible, Preemptive indifferent| Parameters || --- || Does not require any parameters |
