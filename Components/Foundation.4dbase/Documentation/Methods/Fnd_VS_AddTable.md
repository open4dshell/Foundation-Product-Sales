To add a table the developer will normally call the Fnd\_VS\_ShowTable method.We don't use semaphores here. We assume the calling process is using the semaphore.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||table|Pointer|➡️|The table to add|
