One that exists unshared raises -10508 when called.Not thread safe, because METHOD Get attribute is not - probe once and cache the answer rather than asking per call.The name must be literal. METHOD GET NAMES honours the @ wildcard, so a name containing one answers for whatever it happens to match.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||methodName|Text|➡️|Name of the host method||Result|Boolean|⬅️|True when the method exists and is shared|
