Calculated by adding the number of demo days to the demo start date.If the demo hasn't been started, the number of demo days is returned.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inFeatureCode|Text|➡️|The feature code (optional)||Result|Longint|⬅️|Days remaining|
