If multi-window is false, the input form is displayed in the same window as the output form.The setting is for the current process.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inMulti|Boolean|➡️|True to begin multi-window mode (optional)||Result|Boolean|⬅️|True if we're in multi-window mode|
