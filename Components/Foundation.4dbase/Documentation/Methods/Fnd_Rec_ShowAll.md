If the Macintosh Option key or Windows Alt key is down, the selection is reduced to no records.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inTable|Pointer|➡️|A pointer to the table to use (optional)|
