<!--Fnd_Wnd_CloseNow -> Boolean$0 : Boolean : ⬅️ : True if it's time to close the window-->## Fnd\_Wnd\_CloseNowFnd\_Wnd\_CloseNow --> BooleanReturns True if Foundation is trying to close all windows due to the user Option-clicking a window's close box, or if the current form's window has been asked to close by Fnd\_Wnd\_CloseWindow or Close All.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||$0|Boolean|⬅️|True if it's time to close the window|
