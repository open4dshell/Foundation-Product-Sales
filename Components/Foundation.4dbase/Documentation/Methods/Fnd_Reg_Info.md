See the Fnd\_Gen\_ComponentInfo method for more information.Fnd\_Reg licenses the host developer's application, not Foundation: it shows the host's demo and registration dialogs and checks the unlock codes the host issues.Fnd\_Reg needs a [Fnd\_Reg] table in the host: ID Longint, Feature\_Code Alpha 80, Demo\_Days Integer, Demo\_Start\_Date Date, Unlock\_Code Alpha 40, User\_Name Alpha 80, License\_Info Alpha 80 and Checksum Alpha 40. Fnd\_Reg\_Init offers to create it with Fnd\_Reg\_CreateTable.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||request|Text|➡️|Info desired ("version" or "name")||Result|Text|⬅️|Response|
