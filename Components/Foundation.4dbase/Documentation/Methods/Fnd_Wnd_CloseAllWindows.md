If it takes too long for the windows to close, or the user cancels the closing, then False is returned.Do not pass True to this routine from a process that's displaying a window that needs to be closed.  It won't work properly.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||wait|Boolean|➡️|Wait for all windows to close?
