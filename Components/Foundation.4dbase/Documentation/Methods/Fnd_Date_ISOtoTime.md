The input must be in the YYYY-MM-DDThh:mm:ss or hh:mm:ss format.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inIsoDateTime|Text|➡️|An ISO format date-time or time string||Result|Date|⬅️|The time|
