A window already marked is not added again. If the current process has no window yet, the next one it opens with Fnd\_Wnd\_OpenWindow or Fnd\_Wnd\_OpenFormWindow is marked. Nothing happens if another process has no window. See Fnd\_Wnd\_Register for the prime window, which this claims in the same way.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||processNumber|Longint|➡️|Process number (optional)|
