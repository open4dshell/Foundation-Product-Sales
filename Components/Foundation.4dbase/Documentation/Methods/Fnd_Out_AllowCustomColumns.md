Call with a value from Fnd\_Hook\_IO\_DisplayTable to set it for this list; call with nothing to read what applies, which is the application default (Fnd\_Out\_Default with Fnd\_Out\_AllowCustomColumns), the table's allowCustomColumns and this list's value, all of which must allow it. Formulas already added stay listed, under Custom Columns, whatever the answer.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||allow|Boolean|➡️|False to forbid custom columns in this list (optional)||Result|Boolean|⬅️|Whether custom columns are allowed in this list|
