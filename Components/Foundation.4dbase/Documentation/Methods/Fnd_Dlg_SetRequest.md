Optionally sets the default value of the value.  Pass "*" as the default value to cause the entry area to display bullets rather than text.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inDefault|Text|➡️|The default value (optional)|
