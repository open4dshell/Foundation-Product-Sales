This is calculated by adding the number of demo days to the date the demo period was started.If the demo hasn't been started, the number of demo days is added to the current date, and the resulting date is returned.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inFeatureCode|Text|➡️|The feature code (optional)||Result|Date|⬅️|The expiration date|
