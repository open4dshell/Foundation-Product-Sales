Call it once for each field, from Fnd\_Hook\_Out\_SearchFields. A table with no declared fields gets no search box.The first parameter is one of:1. A field pointer: ->[Contacts]LastName2. A text attribute path, for a field reached through relations:"contact.LastName"3. An object, for the tech-savvy: fo\_field is the path, fo\_operator theoperator and fo\_title the title. Each outranks the matching parameter.The title is the field's name in the search box's grey hint and its help tip. It defaults to the field's virtual field name, as Fnd\_VS\_SetFieldTitle gives it; a path with no virtual field name shows its last segment. An operator of "" means begins.```Fnd_Out_AddSearchField(->[Contacts]LastName)Fnd_Out_AddSearchField(->[Contacts]Company; "contains")Fnd_Out_AddSearchField("contact.LastName")Fnd_Out_AddSearchField(New object(fo_field; "contact.LastName"; fo_operator; "keyword"))Fnd_Out_AddSearchField(->[Invoices]InvoiceNumber; ""; "Inv. #")Fnd_Out_AddSearchField("contact.LastName"; "contains"; "Customer")Fnd_Out_AddSearchField(New object(fo_field; "contact.LastName"; fo_title; "Customer"))```Operators, for a text field. A number field is searched only when the search text is a number, and a date field only when it is a date; other types are ignored.```begins    The text starts with the search text. The default.contains  The search text appears anywhere in the text.keyword   The search text is a whole word in the text (4D's % operator).exact     The text is the search text, with @ taken literally.```Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inField|Variant|➡️|A field pointer, a text attribute path, or a search object||inOperator|Text|➡️|begins, contains, keyword or exact (optional; default begins)||inTitle|Text|➡️|The name shown in the hint and help tip (optional; default the virtual field name)|
