If a calling process number is passed ($3) then that process is called if the record is saved.  In this case, Fnd\_IO\_AddRecordNumber\_i will contain the record number of the modified record. Either pass the parameters one after another (a table pointer first), or pass one object holding them all.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||first|Variant|➡️|A pointer to the table to display, or an object||recordNumber|Longint|➡️|Record number (pointer form only)||inCallingProcess|Longint|➡️|Number of the calling process (optional, pointer form only)||inShowLockedMessage|Boolean|➡️|Show Locked Message (optional, pointer form only)|
