If the Fnd\_Loc component is not available, the name will be localized using 4D's language.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||monthNum|Longint|➡️|1 thorugh 12||Result|Text|⬅️|The name of the month|
