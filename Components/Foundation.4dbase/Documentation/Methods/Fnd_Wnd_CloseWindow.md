The window may veto.A prime window with closeable siblings waits: the siblings are asked first, and the prime only once they have all closed. That happens in a background process. Does nothing if the window does not exist.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||window|Integer|➡️|The window reference|
