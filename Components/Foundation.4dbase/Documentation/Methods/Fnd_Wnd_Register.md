Windows opened by Fnd\_Wnd\_OpenWindow are registered automatically, but are kept out of the Window menu and out of Close All until they opt in.The onClose method must be shared ("Shared by components and host database"): Foundation runs it from the component, which cannot see a method that is not.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||window|Integer|➡️|The window reference||options|Object|➡️|Any of the properties below (optional)||options|Text|➡️|The Window-menu text||options|Boolean|➡️|List the window in the Window menu||options|Boolean|➡️|Include the window in Close All||options|Boolean|➡️|See below||options|Boolean|➡️|See below||options|Text|➡️|A project method run inside the window when it is asked to|
