Also returns the current setting.This method replaces the original Fnd\_Wnd\_SetCloseBox method, which is now obsolete.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||closeBox|Boolean|➡️|Add a close box?
