It assumes your method header comments are formatted the way Foundation's are.$options\_o is optional; any property left out takes the default shown: methodName     - "" or omitted: all methods; a prefix (Eg. Inv\_); or one specific method name tooltip        - default True. True writes the leading <!-- --> block into each method's comments; False strips it from every method it touches excludePrivate - default False. True: exclude Private methods and shared aaa methods silent         - default False. True: don't show a final "Finished" alert inline         - default False. True: run in the calling process rather than spawning one. Use in headless/CI contextsFnd\_Dev\_WriteDocumentation({methodName: "Inv\_"; silent: True})Attributes: Shared, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||options|Object|➡️|Options, as described above (optional)|
