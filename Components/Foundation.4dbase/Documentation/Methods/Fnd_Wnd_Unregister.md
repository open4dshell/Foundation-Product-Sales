With no parameter it removes the current process's most recently registered window, which is the one CLOSE WINDOW would close. Does nothing if there is no such entry.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||window|Integer|➡️|The window reference (optional)|
