If not, nothing changes.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||desiredField|Pointer|➡️|The field to default to (optional)||Result|Pointer|⬅️|The selected sort field|
