Call it from a host with the name of one of the host's own lists.```Fnd_VS_zProbeHostLists("VS_Table002_EN")```Each route is reported as an object with a "worked" Boolean and what it found, so one call answers all of them and a failure in one does not hide the rest. A route that raises is silenced and reports worked:False with no further detail: Try...Catch...End try, which could report the error, is 20 R5 and this component still builds on 20.x LTS.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||listName|Text|➡️|The name of a list belonging to the HOST database||Result|Object|⬅️|One property per route attempted|
