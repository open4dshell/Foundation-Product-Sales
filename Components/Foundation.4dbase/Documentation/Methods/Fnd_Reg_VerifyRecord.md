Theoretically this will happen only if the user tampers with a [Fnd\_Reg] record. Otherwise processing is allowed to continue uninterrupted.Assumes that there is exactly one record in the current selection.Fnd\_Reg\_SaveRecord is called to set the checksum.Attributes: Shared, Invisible, Preemptive indifferent| Parameters || --- || Does not require any parameters |
