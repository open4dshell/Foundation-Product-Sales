Each entry is an object: window, process, processName, title, inMenu, closeable, prime, disposable, slot and onClose.The result is a copy: changing it does not change the registry.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||filter|Object|➡️|Return only entries having every property of this object, e.g. {process: 3} or {inMenu: True} (optional)||Result|Collection|⬅️|A non-shared collection of entry objects, oldest first|
