<!--Fnd_Dev_SchedStart Does not require any parameters -->## Fnd\_Dev\_SchedStartFnd\_Dev\_SchedStartStarts the compile-check watcher in your database. The watcher polls <Resources>/schedulerRequest.json in your database's Resources folder every 5 seconds, runs the action it names (a compile check, a test run or a relaunch), and writes the outcome to <Resources>/schedulerResult.json. Your project is the one checked.Call it once from On Startup.A developer tool, driven by the developer and by AI working alongside them.Interpreted mode only. In compiled mode this is a no-op.Stop the watcher with Fnd\_Dev\_SchedStop.Attributes: Shared, Preemptive indifferent| Parameters || --- || Does not require any parameters |
