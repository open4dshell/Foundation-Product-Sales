Fnd\_Menu\_SetMenuItem (1;5;"Print.../P")Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||menuNumber|Longint|➡️|The menu number||itemNumber|Longint|➡️|The menu item number||inLabel|Longint|➡️|The new label, with shortcut if desired|
