Must be run from a new process, but this method handles that.This is necessary because a menu bar can't be installed at startup with the first version of 4D v11 SQL.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inInternally|Longint|➡️|Used internally|
