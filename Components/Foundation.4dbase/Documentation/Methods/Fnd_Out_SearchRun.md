Runs in the context of the list's own form, so the search box calls it through CALL FORM. Does nothing when the text is the same as in the previous search.Fnd\_Hook\_Out\_Search, if the host has it, is tried first; when it returns Null the fields declared by Fnd\_Hook\_Out\_SearchFields are searched.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||searchText|Text|➡️|The text typed in the search box|
