Holding Option (Alt on Windows) while the check finishes puts the concise rather than the indented JSON on the pasteboard.Files edited outside the 4D IDE are picked up first, so the check sees the current source.Interpreted mode only.Attributes: Shared, Preemptive indifferent| Parameters || --- || Does not require any parameters |
