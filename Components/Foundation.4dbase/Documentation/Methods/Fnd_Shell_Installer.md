It lists what is missing and adds it all if you choose Install. A form is copied only if your Forms folder has none of that name, together with the pictures it uses that your Resources folder lacks. It also lists Foundation tables from an earlier version that need a primary key or journaling, and upgrades them; only this method offers an upgrade on its own. It is opened automatically the first time Foundation needs something that is missing, and then lists any upgrades and missing forms too; a missing form alone never opens it. Forms and pictures already in your database that differ from Foundation's are listed for information, marked superseded or edited; Install never changes them, and they alone never open the installer. When nothing is missing, it still opens the page, which says so and lists what has changed in this release, with a Close button.It runs in a process of its own, one at a time; the call returns at once.Attributes: Shared, Preemptive indifferent| Parameters || --- || Does not require any parameters |
