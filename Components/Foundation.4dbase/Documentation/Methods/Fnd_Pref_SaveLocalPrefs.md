<!--Fnd_Pref_SaveLocalPrefs Does not require any parameters -->## Fnd\_Pref\_SaveLocalPrefsFnd\_Pref\_SaveLocalPrefsWrites the preferences file to disk, as JSON.Called from Fnd\_Pref\_SavePrefs, which handles the semaphore.The file is an object of preferences keyed by name, each holding the 4D type code it was stored under and its value in the JSON type that matches:{ "format": 1, "preferences": { "Fnd\_Nav: Open at Startup": { "type": 6,  "value": true }, "Fnd\_Out: Columns":         { "type": 38, "value": { "width": 90 } }, "Fnd\_Nav: Palette Window":  { "type": -1, "value": "10, 20, 310, 220" } } }The type is recorded because JSON cannot tell a long integer from a real, and because a window - type -1 - has no JSON equivalent at all.Only the local preferences are written. The server and shared ones live in [Fnd\_Pref], and a labelled one never reaches the arrays.Attributes: Shared, Invisible, Preemptive indifferent| Parameters || --- || Does not require any parameters |
