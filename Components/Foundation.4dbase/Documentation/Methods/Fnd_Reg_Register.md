Sets the OK variable to 1 if the product gets registered. Sets the Error variable if there's a problem.This doesn't check to see if it's already been registered, so it can be called to change the registration at any time.  But only does the update if the user name and unlock code are valid.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inFeatureCode|Text|➡️|The feature code||inUnlockCode|Text|➡️|Unlock code||userName|Text|➡️|User name|
