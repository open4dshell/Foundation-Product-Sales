Programmatic callers rely on this — Fnd\_Date\_EndOfMonth is day 0 of the following month. Pass through Fnd\_Date\_StringToDate instead when the input came from a person, since that one refuses a month above 12 or a day above 31.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inYear|Longint|➡️|Year (2 or 4 digits)||month|Longint|➡️|Month||day|Longint|➡️|Day||Result|Date|⬅️|The date|
