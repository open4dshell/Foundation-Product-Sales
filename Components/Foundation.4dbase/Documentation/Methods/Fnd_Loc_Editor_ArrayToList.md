This routine always appends an asterisk to the list name, so that we don't mess up the original.See also the Fnd\_Loc\_ListToArray method.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||array|Pointer|➡️|The text array||inListName|Text|➡️|The list name|
