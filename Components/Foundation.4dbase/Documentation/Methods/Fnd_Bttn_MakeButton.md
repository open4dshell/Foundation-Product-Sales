Call Fnd\_Bttn\_GetPicture. It will check the cache first, then call this only if necessary.Supports these variations: "" : A standard button "current" : The currently selected button (Mac OS X Prefs style) "menu" : Adds a menu indicator triangleAttributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||iconName|Text|➡️|The name of the icon to use from the 4D picture library||buttonText|Text|➡️|The label for the button||variation|Text|➡️|The variation name||Result|Picture|⬅️|A picture to use for a 4D picture rollover button|
