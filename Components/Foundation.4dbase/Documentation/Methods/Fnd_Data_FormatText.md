Defaults to "title"stripSpaces Boolean  Whether to strip the spaces first. Defaults to True```Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inTheText|Text|➡️|The text to capitalize||inOptions|Variant|➡️|An options object (optional)||Result|Text|⬅️|The capitalized text|
