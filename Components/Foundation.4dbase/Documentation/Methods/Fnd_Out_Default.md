One parameter reads the stored value (Null when none was set); two store it, last call wins, and return it. Call from the host's startup or from Fnd\_Hook\_IO\_DisplayTable. A list opens from the form's own values, then these, then the table's Resources/Foundation/Fnd\_Out/<Table>.json "appearance", then the user's saved default and the list's own saved definition. The View Options Reset button returns to the first three.Use the constants rather than the strings: Fnd\_Out\_FontName ("fontName") : Text : font of the columns Fnd\_Out\_TextSize ("textSize") : Integer : text size of the columns Fnd\_Out\_RowHeight ("rowHeight") : Integer : row height in lines Fnd\_Out\_RowPixels ("rowPixels") : Integer : row height in pixels, outranks lines Fnd\_Out\_VAlign ("vAlign") : Integer : vertical alignment of the cells: Align top, Align center (the default) or Align bottom. A column's own fo\_vAlign outranks it Fnd\_Out\_Fill ("fill") : Integer : background colour, as OBJECT SET RGB COLORS takes it Fnd\_Out\_AltFill ("altFill") : Integer : alternate background colour Fnd\_Out\_RelationDepth ("maxRelationDepth") : Integer : relations deep the palette offers Fnd\_Out\_MaxColumns ("maxColumns") : Integer : columns of the best-guess layout Fnd\_Out\_AllowCustomColumns ("allowCustom") : Boolean : may users add custom columns (formulas); Null, meaning True, until set Fnd\_Out\_AllowPublish ("allowPublish") : Boolean : may users publish and delete shared layouts; Null, meaning the Designer, the Administrator and the Administration group, until setAn unknown tag, or a value of the wrong type, raises a bug alert, stores nothing and returns Null.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||tag|Text|➡️|One of the tags above||value|Variant|➡️|The value to store (optional)||Result|Variant|⬅️|The stored value, Null when unset or refused|
