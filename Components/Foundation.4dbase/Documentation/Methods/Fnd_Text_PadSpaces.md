If the length of the text is greater than the length paramter, it will be truncated.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inText|Text|➡️|The text to pad||length|Longint|➡️|The desired length||Result|Text|⬅️|The modified text|
