See the Fnd\_Gen\_ComponentInfo method for more information: Fnd\_Gen\_ComponentInfo("Fnd"; "version")Responds to: version: The release version of the component, e.g. 6.0.0-rc.1 info: The full Get Info string (version, 4D target, build date) name: "Foundation"Attributes: Shared, Invisible, Preemptive capable| Parameter | Type |  | Description || --- | --- | --- | --- ||request|Text|➡️|Info desired||Result|Text|⬅️|Response|
