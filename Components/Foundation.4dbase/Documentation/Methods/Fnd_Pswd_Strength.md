Pass rating through Fnd\_Gen\_GetString("Fnd\_Pswd"; "Strength"+String(rating)) for a localized name.By default this counts the pool a guesser would have to search, which is an upper bound rather than a judgement: it cannot know a password is a dictionary word, and it badly overstates a pronounceable one, whose syllables are far more constrained than its letters suggest.So tell it what it is looking at when you know:```Fnd_Pswd_Strength($password_t; {type: Fnd_Pswd_TypePronounceable})```which counts the passwords that shape can actually produce instead — about 79 bits for the three-group default, against the 131 its characters imply.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||password|Text|➡️|The password to weigh||options|Variant|➡️|{ type } — how it was generated, if known (optional)||Result|Object|⬅️|{ length ; poolSize ; bits ; rating }|
