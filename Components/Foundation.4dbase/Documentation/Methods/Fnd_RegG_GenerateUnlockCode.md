The MD5-based codes deter casual copying only; they are not copy protection.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||secretKey|Text|➡️|The unique product secret key||inFeatureCode|Text|➡️|The feature code||personalization|Text|➡️|The user name||inLicenseInfo|Text|➡️|The license information (optional)||inFormat|Text|➡️|The unlock code format (optional)||Result|Text|⬅️|The unlock code|
