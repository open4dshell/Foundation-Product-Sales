The first call for a table switches the palette from "offer everything except what's hidden" to "offer only what's explicitly listed" - every path (or wildcard pattern) passed to Fnd\_Out\_OfferField for that table becomes the only-list a candidate must match to be offered. A column the host's own AddField already defines is unaffected either way.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inPath|Text|➡️|A field path, or a wildcard pattern using "@"|
