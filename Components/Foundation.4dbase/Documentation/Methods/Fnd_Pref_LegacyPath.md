Nothing writes it any more, and it is left on disk rather than deleted so a downgrade still has something to read.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||Result|Text|⬅️|The path to the legacy prefs file|
