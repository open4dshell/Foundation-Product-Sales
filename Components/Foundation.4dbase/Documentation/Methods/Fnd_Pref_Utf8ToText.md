Anything else is passed through, so text that was never doubled is returned unchanged and the method is safe to run over a whole file.Characters above U+07FF cannot be recovered: the old writer had no room for them and produced a first "byte" above 255, which is not a sequence this can read. They are left as they are.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||source|Text|➡️|Text read from a legacy preferences file||Result|Text|⬅️|The same text with any doubled characters collapsed|
