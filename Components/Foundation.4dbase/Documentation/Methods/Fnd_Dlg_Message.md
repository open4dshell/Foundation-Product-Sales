Stays open until it's called again with a blank string.Designed to be a replacement for 4D's MESSAGE command.See also: 4D's own Progress component (Progress New, Progress SET PROGRESS, Progress QUIT), which is the better choice for new code; Fnd\_Dlg\_Message stays for hosts that already call it.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||message|Text|➡️|The message to display|
