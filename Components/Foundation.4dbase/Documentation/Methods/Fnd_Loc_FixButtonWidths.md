Designed to be called after calling Fnd\_Gen\_ButtonText on each of the buttons in the group.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||$1|Pointer|➡️|A pointer to a button||$2..$N|Pointer|➡️|More button pointers|
