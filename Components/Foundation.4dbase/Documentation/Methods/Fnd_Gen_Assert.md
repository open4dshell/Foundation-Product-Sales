A true condition does nothing else.A false condition is reported, never raised:- during a test run, it is recorded as a failure through Fnd\_Test\_Assert;- when Foundation runs interpreted, it opens the debugger;- otherwise it goes to Fnd\_Gen\_BugAlert, which logs it and shows anotification for ten seconds, so the process carries on.```If (Fnd_Gen_Assert($customer_e#Null; "No customer for order "+String($order_e.ID)))	$name_t:=$customer_e.nameEnd if```Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||condition|Boolean|➡️|The assumption||message|Text|➡️|What was expected, and what was found||Result|Boolean|⬅️|The condition, unchanged|
