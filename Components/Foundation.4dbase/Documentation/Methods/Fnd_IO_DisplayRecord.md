If no table is passed, then the current form's table is used (if available).  If no record number is passed, then the current record will be displayed.  Pass 4D's New record constant to create a new record. Either pass the parameters one after another (a table pointer first), or pass one object holding them. Every property of the object is optional and behaves as the omitted parameter does.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||first|Variant|➡️|Pointer to the record's table, or an object (optional)||inRecordNumber|Longint|➡️|Record number (optional, pointer form only)||inShowlockedmessage|Boolean|➡️|Show Locked Message (optional, pointer form only)||Result||⬅️|Process number of the (new?) process displaying the record.|
