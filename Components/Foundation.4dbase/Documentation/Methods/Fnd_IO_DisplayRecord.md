If no table is passed, then the current form's table is used (if available).  If no record number is passed, then the current record will be displayed.  Pass 4D's New record constant to create a new record.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inTable|Pointer|➡️|Pointer to the record's table (optional)||inRecordNumber|Longint|➡️|Record number (optional)||inShowlockedmessage|Boolean|➡️|Show Locked Message (optional)||Result||⬅️|Process number of the (new?) process displaying the record.|
