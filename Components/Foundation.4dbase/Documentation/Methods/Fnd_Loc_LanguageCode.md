If a language code is passed to this routine, it's set as the new localization code.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inCode|Text|➡️|The language code to use (optional)||Result|Text|⬅️|The current langauge code|
