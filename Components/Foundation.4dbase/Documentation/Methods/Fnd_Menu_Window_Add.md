If no title is specified, the current window title is used. Call it after opening the window.The prime window is the one whose closing lets the process method carry on: the window opened just before a blocking DIALOG (without *), ADD RECORD, MODIFY RECORD, MODIFY SELECTION or DISPLAY SELECTION. Close All closes it last of its process. Left out, a window added from process-method level, before the blocking call, is taken to be prime, and one added from inside a running form is not. Pass False for a window opened with DIALOG(...; *) from process-method level, because the process carries on after it. Pass True to claim prime from inside a form. See Fnd\_Wnd\_Register.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inItemText|Text|➡️|The item text to add to the menu (optional)||prime|Boolean|➡️|Is this the process's prime window?
