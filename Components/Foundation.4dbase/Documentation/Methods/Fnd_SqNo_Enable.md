Optionally starts the numbering at the specified number.  Otherwise it starts at 1.The new group will be editable by the database administrator.Doesn't change the [Fnd\_SqNo] table's read/write state.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||groupName|Text|➡️|The group name||inStartNumber|Longint|➡️|The starting number (optional)|
