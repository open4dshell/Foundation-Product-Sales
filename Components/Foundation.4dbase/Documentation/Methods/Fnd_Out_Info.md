See the Fnd\_Gen\_ComponentInfo method for more information.Responds to: • version - what version. • name - the name of the module. • state - Is Fnd\_Out active for THIS process? (active/inactive) • highlighted - the number of records highlighted in the listbox. • inSelection - the number of records displayed in the listbox. • inTable - the number of records in the table.Numeric codes: -1 : Fnd\_Out is not active in this process -2 : Called oustde the context of the Fnd\_Out form -3 : Called in the Fnd\_Out form, but object not yet initialised/touched (most likely On Load Form Event).Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||request|Text|➡️|Info desired||Result|Text|⬅️|Response (convert to string for numbers)|
