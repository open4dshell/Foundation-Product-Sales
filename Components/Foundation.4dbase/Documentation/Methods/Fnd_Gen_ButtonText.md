Also moves any adjacent form objects so they stay properly aligned with the modified button.Due to a bug in 4D 2003.1, this routine won't work properly if the primary button is set as the default button.  If this is a problem, UPGRADE!Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||button|Variant|➡️|A pointer to the button, or its name||text|Text|➡️|New button text||alignment|Longint|➡️|Which end to keep stationary (optional)||$4..$N|Variant|➡️|Other form objects to move, by pointer or by name||Result|Longint|⬅️|The increase in the button size|
