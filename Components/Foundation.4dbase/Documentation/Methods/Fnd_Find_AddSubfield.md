The field type must be specified because we can't procedurally determine this like we can for fields.  If a position isn't specified, the field is added to the end of the list.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||field|Pointer|➡️|A pointer to the field to add||fieldType|Longint|➡️|The type of the subfield||inPosition|Longint|➡️|The position in which to add the item (optional)|
