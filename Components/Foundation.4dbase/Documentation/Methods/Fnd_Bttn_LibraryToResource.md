<!--Fnd_Bttn_LibraryToResource-->## Fnd\_Bttn\_LibraryToResourceFnd\_Bttn\_LibraryToResourceTakes all the pictures in the 4D Picture Library and writes them to a separate .png file for each picture in the library in the 4D Resources folder in a folder named Fnd\_Bttn\_Pictures.Used by Fnd\_Bttn subcomponent to allow developer to easily edit or replace the icons used throughout Foundation.Special thanks to John Craig for this implementation.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- |
