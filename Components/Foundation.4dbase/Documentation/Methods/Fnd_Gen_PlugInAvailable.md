This is done by executing a valid call to the plug-in, then checking to see if 4D set the Error variable to something other than zero.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||plugIn|Text|➡️|The name of the plug-in||Result|Boolean|⬅️|True if the plug-in is available|
