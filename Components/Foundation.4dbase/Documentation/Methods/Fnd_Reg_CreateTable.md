Fnd\_Reg\_Init offers to call it; a developer can also call it directly. If the table already exists, nothing is changed.The table it creates: ID               Longint, primary key Feature\_Code     Alpha 80 (Fnd\_Reg\_Init indexes it) Demo\_Days        Integer Demo\_Start\_Date  Date Unlock\_Code      Alpha 40 User\_Name        Alpha 80 License\_Info     Alpha 80 Checksum         Alpha 40In a compiled host, or on a remote client, it changes nothing and returns success False with a message. After it creates the table, restart the host before using Fnd\_Reg.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||Result|Object|⬅️|{ success : Boolean ; created : Boolean ; restartRequired : Boolean ; message : Text }|
