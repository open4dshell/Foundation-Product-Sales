<!--Fnd_Pref_LoadLegacyPrefs Does not require any parameters -->## Fnd\_Pref\_LoadLegacyPrefsFnd\_Pref\_LoadLegacyPrefsReads the Apple property list that versions before the JSON file wrote, and puts what it holds into the preference arrays. Called by Fnd\_Pref\_LoadLocalPrefs when there is no JSON file yet, so an existing installation converts itself the first time it runs.Nothing writes this file any more. It is left on disk rather than deleted, so a downgrade still finds it; the next save writes JSON and the JSON is read from then on.Attributes: Shared, Invisible, Preemptive indifferent| Parameters || --- || Does not require any parameters |
