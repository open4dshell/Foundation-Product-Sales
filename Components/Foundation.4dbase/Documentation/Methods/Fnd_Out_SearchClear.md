Called by the box's clear button, which also shows every record, and by Fnd\_Gen\_SelectionChanged through EXECUTE METHOD IN SUBFORM, which passes False because the list has already been replaced.Runs in the Fnd\_Out\_Search subform.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||runSearch|Boolean|➡️|Show every record and focus the box (optional, default True)|
