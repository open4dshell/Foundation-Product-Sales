This routine will take care of adding it to the output list (if any).This routine can also be called by the output list process to get the number of the most recently edited record. Once called to get the record number, it clears it so you won't accidentally get it again.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||table|Pointer|➡️|A pointer to the record's table||inCallingProcess|Longint|➡️|The process number of the output form||Result|Longint|⬅️|The record number that was edited|
