The input can be in either of these formats: YYYY-MM-DD YYYY-MM-DDThh:mm:ssAttributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||isoDate|Text|➡️|An ISO format date||Result|Date|⬅️|The date|
