For example, &gt; is converted to >.Unlike HTML encoding, this routine only handles reserved XML characters, since accented characters are handled by the UTF-8 encoding.Call Fnd\_Pref\_XmlEncode to reverse the process.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inText|Text|➡️|An encoded text string||Result|Text|⬅️|The unencoded text string|
