Functions whose names begin with an underscore are left out. A class with no live code has no page, and any page it had is removed.Takes no parameters and shows no alert, so it is safe to drive headlessly.Attributes: Shared, Preemptive indifferent| Parameters || --- || Does not require any parameters |
