The default, when this is never called, is 5.Call from wherever the host configures Fnd\_Out for a table (alongside Fnd\_Out\_AddField calls). Mutates the in-memory developer configuration only, exactly as Fnd\_Out\_HideField does.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inDepth|Integer|➡️|The most relations a candidate's path may cross|
