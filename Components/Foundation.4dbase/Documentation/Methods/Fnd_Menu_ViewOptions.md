Opens the single, shared View Options palette process (Fnd\_Out\_ViewOptionsProcess) if it isn't already running, or brings its window to front if it is - never a second palette. The palette serves whichever list window is front, retargeting through Fnd\_Out\_ViewOptionsFront as focus moves between Foundation windows; this method only needs to get it open or forward.Runs with Form bound to the Fnd\_Out form, since it's reached from Fnd\_Out's own menu bar while its window is front - the same context Fnd\_Menu\_Sort relies on to reach Form.listData directly.Attributes: Shared, Invisible, Preemptive indifferent| Parameters || --- || Does not require any parameters |
