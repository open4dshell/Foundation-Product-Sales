<!--Fnd_SqNo_CreateTable Does not require any parameters -->## Fnd\_SqNo\_CreateTableFnd\_SqNo\_CreateTableCreates the [Fnd\_SqNo] table in the host when it does not exist yet, and waits until it can be used. Does nothing when Foundation runs on its own rather than in a host. Called from the Application process, it does the work in a new process and waits for it.Attributes: Shared, Invisible, Preemptive indifferent| Parameters || --- || Does not require any parameters |
