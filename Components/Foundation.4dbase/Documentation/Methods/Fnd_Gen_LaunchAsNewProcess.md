If the process is alreadyrunning, it's just brought to the front.The method you name must be shared ("Shared by components and host database"): Foundation runs it from the component, which cannot see a method that is not.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||methodName|Text|➡️|The method name to launch||newProcessName|Text|➡️|The name to give the new process||Result|Boolean|⬅️|True if we're in a new process|
