It stays open, and stays in Close All Windows. With no parameter, the current process's most recently added window is removed. A parameter that is a window reference removes that window; any other number is taken as a process number and removes all of that process's windows.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inNumber|Longint|➡️|Window reference or process number (optional)|
