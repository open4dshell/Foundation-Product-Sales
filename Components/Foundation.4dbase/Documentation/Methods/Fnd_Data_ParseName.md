Every pointer is optional.```$name_o:=Fnd_Data_ParseName("Dr. John Q. Smith"){first: "John"; last: "Smith"; middleInitial: "Q"}Fnd_Data_ParseName("Dr. John Q. Smith"; ->$first_t; ->$last_t; ->$initial_t)```Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inFullName|Text|➡️|The name to parse||firstName|Pointer|➡️|Gets the first name (optional)||lastName|Pointer|➡️|Gets the last name (optional)||middleInitial|Pointer|➡️|Gets the middle initial (optional)||Result|Object|⬅️|The parts, as first, last and middleInitial|
