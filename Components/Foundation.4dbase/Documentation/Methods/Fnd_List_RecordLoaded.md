If it is, it waits a while to see if the record becomes avaialble.If no timeout period is specified control is returned immediately if the record is locked.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||table|Pointer|➡️|The record's table||inSecondsToWait|Longint|➡️|Number of seconds to wait if it's locked (optional)||Result|Boolean|⬅️|True if the record isn't locked|
