It will return Y, M, and D based in a format like this: "M/D/Y" = Month/Day/Year "D/M/Y" = Day/Month/YearAttributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||Result|Text|⬅️|The date format|
