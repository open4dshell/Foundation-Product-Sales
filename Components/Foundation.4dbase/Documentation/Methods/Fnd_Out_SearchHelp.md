A single name is never shortened.A host can call it from Fnd\_Hook\_Out\_SearchFields, after the Fnd\_Out\_AddSearchField lines, to include the list in a tooltip it gives to Fnd\_Out\_SearchHint.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||maxLength|Integer|➡️|The longest text wanted (optional; default every name)||Result|Text|⬅️|The searched fields' names|
