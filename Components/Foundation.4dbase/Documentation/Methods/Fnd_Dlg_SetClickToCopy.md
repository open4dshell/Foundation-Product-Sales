While it is on, a click on the dialog's text puts that text on the pasteboard: the heading, a blank line, then the details.It is off until this is called, and the setting is shared by every process, so one call at startup is enough.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||enable|Boolean|➡️|True to turn click-to-copy on, False to turn it off|
