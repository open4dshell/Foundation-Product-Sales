Returns the current value of the maximum password length.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inMaxChars|Longint|➡️|The maximum password length setting (optional)||inMaxLimitation|Longint|➡️|The maximum value displayed in the pop-up menu (optional)||Result|Longint|⬅️|The currently set maximum length|
