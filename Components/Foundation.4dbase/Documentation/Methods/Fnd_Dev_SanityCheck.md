Reads the sources on disk, so run it interpreted. Nothing is shown on screen.```$result_o:=Fnd_Dev_SanityCheck$result_o.counts.error, .warning, .note; $result_o.findings[0].message```The compile-check watcher runs the same sweep on {"action": "sanity"}.Attributes: Shared, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||Result|Object|⬅️|findings (collection of {check; severity ("error", "warning" or      "note"); where; message}), counts ({error; warning; note}), checks (names run),      forms, methods (numbers read) and ms (time taken)|
