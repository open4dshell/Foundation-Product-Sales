The formula is normalised (trimmed) before it's compared or stored, exactly as Fnd\_Out\_AddField normalises a "Formula: " fo\_field, so the two never drift into near-duplicate text. A formula the host has already added as a real column through Fnd\_Out\_AddField is not duplicated - Fnd\_Out\_CandidateColumns skips a declared formula that matches an already-defined column.Calling this twice for the same formula (after trimming) is a no-op - the second call is silently ignored rather than adding a duplicate entry.A host method called from the formula must be shared ("Shared by components and host database"): Foundation evaluates the formula in the component, which cannot see a method that is not.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inFormula|Text|➡️|The formula expression, e.g. "This.fullName()"||inTitle|Text|➡️|The column header offered for it||inType|Integer|➡️|The 4D field type the formula returns|
