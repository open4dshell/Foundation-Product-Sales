The calling process follows the new default if it was using the old default filename. Existing named logs and filenames selected by other processes keep their extensions.Explicit filename extensions override this preference. Nothing is saved to disk.Case, Unicode, internal spaces and dots are preserved. Rejects ASCII 0-31, <>:"/\|?*, and a trailing dot or space. Invalid input leaves the setting unchanged.Full filename and path-length limits still depend on the target filesystem.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inExtension|Text|➡️|Extension with an optional leading dot; empty resets to .txt (optional)||Result|Text|⬅️|Current preferred extension, including the leading dot|
