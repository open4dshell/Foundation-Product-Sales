Call this once at startup to change it:```Fnd_Text_MD5Encoding("UTF-8")```ASCII hashes the same under either, so this only affects text carrying characters above 127. Changing it invalidates any stored digest of such text.The setting is shared, so it applies to every process in the host.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||inCharset|Text|➡️|The charset name, as CONVERT FROM TEXT understands it (optional)||Result|Text|⬅️|The charset now in force|
