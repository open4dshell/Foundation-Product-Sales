If the group doesn't already exist, it is created and 1 is returned as the first number.Attributes: Shared, Invisible, Preemptive indifferent| Parameter | Type |  | Description || --- | --- | --- | --- ||groupName|Text|➡️|The group name||Result|Longint|⬅️|The next number in the sequence|
