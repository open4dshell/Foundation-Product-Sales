## cs.fnd.log Created by WBS, 2026-09-12 (FND-26) Logging access for hosts: cs.fnd.log.new(). No shared singleton syntax. Status: a first step, not a complete API. This class covers part of the Fnd_Log module and shows the direction Foundation's code is taking; the Fnd_Log_ methods remain the complete, supported interface, and more functions will follow in later releases. Delegates to methods; enabled/selection remain in the calling process. A future 21 singleton can use the same functions without sharing process state.### enable```4denable($enabled_b : Boolean)->$result_b : Boolean``` Read or set the current process enable flag.### config```4dconfig($options_o : Object)->$result_o : Object``` Read or update application defaults; declared logs keep their settings.### declareLog```4ddeclareLog($label_t : Text; $file_t : Text; $folder_t : Text; $options_o : Object; $dedicated_b : Boolean)``` Declare once; optional dedicated writer defaults to False.### useLog```4duseLog($label_t : Text)``` Empty/omitted selects default; does not alter enable state.### label```4dlabel()->$result_t : Text``` Current process log label.### overrideLevel```4doverrideLevel($level_i : Integer; $application_b : Boolean)->$result_i : Integer``` No arguments reads effective threshold. Optional True sets application scope.### addEntry```4daddEntry($message_v : Variant; $options_o : Object)``` Text or a collection of text columns, plus optional entry metadata.### flush```4dflush($label_t : Text)``` Queue a flush; no completion acknowledgement.### closeLog```4dcloseLog($label_t : Text)``` Flush and close a label, or all logs when omitted.### createTable```4dcreateTable()->$result_o : Object``` Explicit only; interpreted host required. Inspect restartRequired.### shutdown```4dshutdown()``` Call after producers finish, outside a logger worker.### extension```4dextension($value_t : Text)->$result_t : Text``` Omit to read; pass text to update through Fnd_Log_Extension.### fileName```4dfileName($value_t : Text)->$result_t : Text``` Omit to read; pass text to update through Fnd_Log_FileName.### path```4dpath($value_t : Text)->$result_t : Text``` Omit to read; pass text to update through Fnd_Log_Path.### maximumSize```4dmaximumSize($bytes_i : Integer)->$result_i : Integer``` Get/set rollover size; zero disables rollover.### info```4dinfo($request_t : Text)->$result_t : Text``` Existing module name/version/logging query API.
