## cs.fnd.text Created by: Wayne Stewart (Claude Opus 5) (2026-08-13) WBS, 2026-09-12 - Expose existing whitespace trim through the class.The Fnd_Text module as a class, so a host can reach it through the class storeinstead of the method names.Status: a first step, not a complete API. This class covers part of theFnd_Text module and shows the direction Foundation's code is taking; theFnd_Text_ methods remain the complete, supported interface, and morefunctions will follow in later releases. In a host:        cs.fnd.text.new().capitalize("hello world") Inside Foundation: cs.text.new().capitalize("hello world")The namespace is the "Component namespace in the class store" setting, which is"fnd" here. It governs how the host sees these classes; inside the componentthey are plain cs.<name>.Design decisions and assumptions:- Every function delegates to the Fnd_Text_ method of the same behaviour. The  methods remain the implementation, so the class cannot drift from them and  adds no behavioural risk. The direction can invert later, one function at a  time, without either API changing.- Stateless, so new() is cheap and instances are interchangeable. Module state  lives in Storage.Fnd.Text, shared by both routes.- 4D 20 LTS has no singletons, so a host instantiates: cs.fnd.text.new(). From  21 a shared singleton would allow cs.fnd.text.me, and the functions below  would not change.- Named for what they do rather than transcribing the method names, so  Fnd_Text_TextToMD5 becomes toMD5 and Fnd_Text_Base64ToText becomes fromBase64.### info```4dinfo($infoRequested_t : Text)->$result_t : Text``` The module's own labels — "name" and "version".### capitalize```4dcapitalize($theText_t : Text; $options_i : Integer)->$result_t : Text``` Book title capitalisation. Option 4 skips the exclude word list.### capitalizeExclude```4dcapitalizeExclude($words_c : Collection)->$result_c : Collection``` Pass a collection to replace the exclude word list, or nothing to read it.### padSpaces```4dpadSpaces($theText_t : Text; $length_i : Integer)->$result_t : Text``` Pads with spaces, or truncates, to exactly $length_i characters.### stripSpaces```4dstripSpaces($theText_t : Text; $options_i : Integer; $altSpaces_t : Text)->$result_t : Text``` 1 leading, 2 trailing, 4 doubles, added together. Default is 1+2.### trim```4dtrim($theText_t : Text)->$result_t : Text``` Trim both ends using Fnd_Text_Trim's whitespace set; preserve NBSP.### wrap```4dwrap($theText_t : Text; $lineLength_i : Integer)->$result_t : Text``` Wraps at the last space before the limit, joined by carriage returns.### equalStrings```4dequalStrings($stringOne_t : Text; $stringTwo_t : Text)->$result_b : Boolean``` Case and diacritic sensitive, unlike 4D's = operator.### formatNumber```4dformatNumber($theNumber_t : Text; $theFormat_t : Text)->$result_t : Text``` Strips punctuation from the number, then applies the 4D number format.### toMD5```4dtoMD5($theText_t : Text; $charset_t : Text)->$result_t : Text``` Defaults to ISO-8859-1, which is what Foundation has always hashed.### md5Encoding```4dmd5Encoding($charset_t : Text)->$result_t : Text``` Sets the charset every later toMD5 uses, or reads it when passed nothing.### toBase64```4dtoBase64($theText_t : Text)->$result_t : Text``` Base64 on one line: BASE64 ENCODE does not wrap at 76 characters.### fromBase64```4dfromBase64($theText_t : Text)->$result_t : Text``` The reverse of toBase64.### encodeBase64```4dencodeBase64($theBlob_x : Blob)->$result_x : Blob``` Takes and returns a blob, rather than the pointer the method wants.### decodeBase64```4ddecodeBase64($theBlob_x : Blob)->$result_x : Blob``` Takes and returns a blob, rather than the pointer the method wants.
