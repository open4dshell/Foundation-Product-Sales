## cs.fnd.pref Created by: Wayne Stewart (Claude Opus 5) (2026-08-14)The Fnd_Pref module as a class, so a host can reach it through the class storeinstead of the method names.Status: a first step, not a complete API. This class covers part of theFnd_Pref module and shows the direction Foundation's code is taking; theFnd_Pref_ methods remain the complete, supported interface, and morefunctions will follow in later releases. In a host:         cs.fnd.pref.new().getText("Report: Last Folder"; "") Inside Foundation: cs.pref.new().getText("Report: Last Folder"; "")The namespace is the "Component namespace in the class store" setting, which is"fnd" here. It governs how the host sees these classes; inside the componentthey are plain cs.<name>.Not to be confused with cs.Fnd_Pref, which is the DataClass extension for the[Fnd_Pref] table and belongs to the host that owns the table. This one is themodule's API and belongs to the component.Design decisions and assumptions:- Every function delegates to the Fnd_Pref_ method of the same behaviour. The  methods remain the implementation, so the class cannot drift from them and  adds no behavioural risk.- Stateless, so new() is cheap and instances are interchangeable. Module state  lives in Storage.Fnd.Pref, shared by both routes.- getWindow is the one place the shape changes rather than passing through. The  method writes through four pointers, which is not something to publish on a  modern API, so this returns {left; top; right; bottom} - or Null when nothing  is stored, which the pointer form signals by leaving the caller's variables  alone.- The scope argument is a constant or a label, the same Variant the methods  take. On a getter it only says where to store a default it has to create; on  remove it says where to delete from. See the method headers.- 4D 20 LTS has no singletons, so a host instantiates: cs.fnd.pref.new(). From  21 a shared singleton would allow cs.fnd.pref.me, and the functions below  would not change.### info```4dinfo($infoRequested_t : Text)->$result_t : Text``` The module's own labels — "name" and "version".### path```4dpath()->$result_t : Text``` Where the local preferences file is, or would be.### userName```4duserName($name_t : Text)->$result_t : Text``` The name the server preferences are owned by. Setting it reloads.### save```4dsave()``` Writes the local file and the user's server preferences. Called on quit.### getText```4dgetText($name_t : Text; $default_t : Text; $scope_v : Variant)->$result_t : Text``` The stored text, or the default. Passing a default stores it when the   preference does not exist yet; the scope says where.### getBoolean```4dgetBoolean($name_t : Text; $default_b : Boolean; $scope_v : Variant)->$result_b : Boolean``` As getText, for a Boolean.### getLongInt```4dgetLongInt($name_t : Text; $default_i : Integer; $scope_v : Variant)->$result_i : Integer``` As getText, for an Integer.### getReal```4dgetReal($name_t : Text; $default_r : Real; $scope_v : Variant)->$result_r : Real``` As getText, for a Real.### getObject```4dgetObject($name_t : Text; $default_o : Object; $scope_v : Variant)->$result_o : Object``` As getText, for an Object.### getWindow```4dgetWindow($name_t : Text)->$result_o : Object``` The stored rectangle as {left; top; right; bottom}, or Null when there isnone. Fnd_Pref_GetWindow signals that by leaving the caller's variablesuntouched, so the four are seeded with something no window could hold andthe result is Null if the seed survived. ### setText```4dsetText($name_t : Text; $value_t : Text; $scope_v : Variant)``` Stores the value. The scope decides local or server; the default is the   module's, see the method header.### setBoolean```4dsetBoolean($name_t : Text; $value_b : Boolean; $scope_v : Variant)``` As setText, for a Boolean.### setLongInt```4dsetLongInt($name_t : Text; $value_i : Integer; $scope_v : Variant)``` As setText, for an Integer.### setReal```4dsetReal($name_t : Text; $value_r : Real; $scope_v : Variant)``` As setText, for a Real.### setObject```4dsetObject($name_t : Text; $value_o : Object; $scope_v : Variant)``` As setText, for an Object.### setWindow```4dsetWindow($name_t : Text; $rect_o : Object)``` Pass {left; top; right; bottom}, or nothing for the frontmost window of   the current process.### remove```4dremove($name_t : Text; $scope_v : Variant)->$result_b : Boolean``` True if there was one to delete. The scope says where to delete from.
