## cs.fnd.fnd Created by: Wayne Stewart, Foundation 5 Wayne Stewart (Claude) 2026-08-01 -> 2026-12-01 - Prepare Foundation 6 releaseFoundation as a whole through the class store: its release information, thecurrent table and form type, and the labels components publish to each other.Status: a first step, not a complete API. This class covers part of theFnd_Gen module and shows the direction Foundation's code is taking; theFnd_Info and Fnd_Gen_ methods remain the complete, supported interface, andmore functions will follow in later releases. In a host:         cs.fnd.fnd.new().info("version") Inside Foundation: cs.fnd.new().info("version")The namespace is the "Component namespace in the class store" setting, which is"fnd" here. It governs how the host sees these classes; inside the componentthey are plain cs.<name>.Design decisions and assumptions:- Every function delegates to the shared Foundation method of the same  behaviour, so the class cannot drift from it.- Stateless, so new() is cheap and instances are interchangeable. The current  table and form type are Foundation's per-process state, the same ones the  methods read and set.- The component-label store lives on the Form object, so setComponentInfo,  getComponentInfo and componentCheck only work while a form is loaded.### info```4dinfo($infoRequested_t : Text)->$result_t : Text``` Foundation's own labels: "version" (the release version, e.g. 6.0.0-rc.1),   "info" (the full Get Info string) and "name". Anything else is not recognised.### getCurrentTable```4dgetCurrentTable->$result_ptr : Pointer``` The current table, or a nil pointer when none is current. Falls back to   the current form's table, then the current trigger's.### setCurrentTable```4dsetCurrentTable($table_ptr : Pointer)->$result_ptr : Pointer``` Makes the table the current one, and returns it.### getCurrentFormType```4dgetCurrentFormType->$result_i : Integer``` The type of the displayed form: 0 Fnd_Gen_NoForm, 1 Fnd_Gen_UnknownForm,   2 Fnd_Gen_OutputForm, 3 Fnd_Gen_InputForm, 4 Fnd_Gen_PreferencesForm,   5 Fnd_Gen_AboutForm.### setComponentInfo```4dsetComponentInfo($key_t : Text; $value_t : Text)->$result_t : Text``` Publishes one label for another component to read, and returns it. The   store lives on the Form object, so this only works while a form is loaded.### getComponentInfo```4dgetComponentInfo($key_t : Text)->$result_t : Text``` Reads back a label another component published. Empty when there is none,   or when no form is loaded.### componentCheck```4dcomponentCheck($calling_t : Text; $required_t : Text)->$result_b : Boolean``` True when the required component answers. False alerts the developer first,   and does not stop the caller — test the result and decide.
