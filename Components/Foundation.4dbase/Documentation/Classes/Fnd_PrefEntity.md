## cs.fnd.Fnd_PrefEntity Created by: Wayne Stewart, Created: 2026-04-28 Entity extension for the [Fnd_Pref] dataclass. Adds typed value access on top of the (Type, Value) column pair. Value is stored as text; Type records the original 4D type so it can be decoded on read. Supported types: Is text, Is longint, Is real, Is boolean, Is object.### typedValue```4dtypedValue() : Variant```### setTypedValue```4dsetTypedValue($value : Variant)``` Encodes $value into (Type, Value) on this entity. Caller saves.Numerics stored as plain text. Booleans stored as "true" / "false".Objects stored as pretty-printed JSON.
