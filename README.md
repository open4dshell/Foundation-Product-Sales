# Foundation Product Sales

The demo and test database for [Foundation](https://foundation.open4dshell.com),
the open-source application shell component for 4D. It has shipped with
Foundation since Dave Batton's first release and shows a complete host: the
`Fnd_Hook_*` and `Fnd_Host_*` methods a host supplies, Foundation's input and
output forms on real tables, toolbars, preferences, localisation (EN and FR)
and the About box.

## Running it

1. Download Foundation for your 4D from <https://foundation.open4dshell.com>:
   20 LTS, 20 R, 21 LTS or 21 R, as a macOS DMG or a Windows ZIP.
2. Put `Foundation.4dbase` in `Components/` (there is a note there saying so).
3. Open `Project/Foundation Product Sales.4DProject` in 4D 20 LTS or later.

## Reporting problems

Open an Issue in this repository, saying which 4D and which Foundation target
you used. During the Foundation 6 beta this is also the place for Foundation
problems found through this database.
